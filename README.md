# Método DAPEN+R

El **Método DAPEN+R** es un método para redactar prompts creado por **Daniel Peña**, de DAPEN Centro de Estudios (Valencia). Se compone de siete componentes: **Rol, Acción, Datos, Público, Estilo, Negación y Revisión**.

## Los siete componentes

Cada componente responde a una pregunta. Se escriben en este orden, uno por línea.

| Componente | Pregunta guía |
|---|---|
| **Rol** | ¿Qué papel debe adoptar la IA? |
| **Acción** | ¿Qué tiene que hacer exactamente? |
| **Datos** | ¿Con qué información trabaja? |
| **Público** | ¿A quién va dirigido el resultado? |
| **Estilo** | ¿Con qué tono y formato? |
| **Negación** | ¿Qué debe evitar? |
| **Revisión** | ¿Qué debe comprobar antes de entregarlo? |

## ¿Qué significa DAPEN+R?

**DAPEN** recoge cinco componentes: **D**atos, **A**cción, **P**úblico, **E**stilo y **N**egación. La **+R** añade las dos **R**: **R**ol, que abre el prompt, y **R**evisión, que lo cierra.

## Un ejemplo sencillo

Encargo: *un correo para recordar a un cliente el pago de una factura.*

```text
Rol: Eres un responsable de administración.
Acción: Escribe un correo para recordar el pago de una factura.
Datos: Factura 2026-045, 350 €, venció el 15 de octubre. Es el primer aviso.
Público: La persona de contabilidad del cliente.
Estilo: Amable y firme. Trato de usted. Máximo 100 palabras.
Negación: Sin amenazas ni reproches.
Revisión: Antes de entregarlo, comprueba que aparecen la factura, el importe y la fecha.
```

Los datos del ejemplo son ficticios. Los resultados de la IA pueden variar: revisa siempre el texto antes de usarlo.
